# IvoChess Clock

A DIY physical chess clock built on an ESP32-C6 (Seeed XIAO ESP32C6), with a
2.13" Waveshare e-paper display, a WS2812 LED strip, and battery power. It
shows your live chess.com game — player names/ratings, move count, clocks
that tick between updates, whose turn it is, and the result when the game
ends — without needing a phone or a PC nearby once it's set up. It's
independent of any physical board or app: it talks straight to chess.com's
own servers, the same way the website does.

**Full docs — hardware list, soldering guide, 3D-printed case, firmware
build/flash instructions, daily use, webadmin, and how to safely connect
your chess.com account — live on the project site:**
